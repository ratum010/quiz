
# Quiz de Perguntas e respostas

O software consiste em fazer perguntas que são escolhidas de forma aleatorias, tiradas do arquivo JSON, vem com alternativas, são perguntas variadas de GEOGRAFIA, HISTORIA, MATEMATICA etc... Após o fim, que acontece quando ha um erro em uma questão, voçê pode salvar seu progresso em um arquivo JSON que sera gerado contendo um dicionario com nome e pontuação, sera salvo a maior pontuação entre a já salva e a conquistada na jogatina, voçê sera reconhecido quando digitar seu nome

## Habilidades desenvolvida 
- Manipulação de arquivos txt e JSON
- Bibliotecas(regex, random, os)
- Estrutura WHILE
